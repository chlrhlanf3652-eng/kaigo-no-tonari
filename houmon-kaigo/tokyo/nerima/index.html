はじめての方へ：3分でわかる流れ

訪問介護は、ホームヘルパーが自宅を訪問して、入浴・排せつ・食事などの「身体介護」と、調理・洗濯・掃除などの「生活援助」を行う介護保険サービスです。利用するには、まず要介護認定を受け、ケアマネジャーにケアプランを作ってもらう必要があります。練馬区には訪問介護事業所が約180件あり、そのなかから希望の曜日・時間帯に対応できるところを探すことになります。

練馬区の最初の相談先は「地域包括支援センター」
練馬区では地域包括支援センターを区内各地に設置しています。要介護認定の申請方法、ケアマネジャー探し、サービスの選び方まで無料で相談できます。どの事業所を選ぶか迷ったら、まずここへ連絡してください。担当の窓口はお住まいの町名で決まります。

料金の目安（練馬区は1級地）

介護報酬は「単位」で決められ、1単位あたりの金額は地域によって異なります。練馬区を含む東京23区は最も高い1級地（訪問介護は1単位＝11.40円）にあたります。自己負担が1割の方の目安は次のとおりです。

頼めること・頼めないこと

訪問介護は「利用者本人の日常生活を支えるため」のサービスです。家族のための家事や、日常生活の範囲を超える作業は介護保険では頼めません。ここを誤解したままだと、サービス開始後にトラブルになりやすいポイントです。

保険で頼めないことは「自費サービス」で補えます。多くの事業所が介護保険外の自費プラン（1時間2,500円〜4,000円程度）を用意しています。草むしりや大掃除は家事代行準備中、食事の準備は宅配弁当・配食サービスと組み合わせるのが現実的です。

相談から利用開始までの4ステップ

  1. 地域包括支援センターに相談するお住まいの地区の担当窓口へ電話または来所。困っている状況を伝えれば、必要な手続きを案内してもらえます。相談は無料です。
  2. 要介護認定を申請する区の窓口または地域包括支援センター経由で申請。認定調査と主治医意見書をもとに、原則30日以内に「要支援1〜2／要介護1〜5」の結果が通知されます。
  3. ケアマネジャーを決め、ケアプランを作る居宅介護支援事業所と契約し、担当ケアマネジャーが本人・家族の希望を聞き取ってケアプランを作成します。ケアプラン作成の自己負担はありません。
  4. 訪問介護事業所と契約し、サービス開始ケアマネジャーから紹介された候補、または自分で探した事業所と契約。サービス担当者会議を経て訪問が始まります。合わなければ後から変更もできます。

失敗しない事業所の選び方

1. 「家から近い」を最優先にしない

距離より、希望する曜日・時間帯にヘルパーを確保できるかが重要です。朝の起床介助や夕方の食事介助は依頼が集中するため、近所でも埋まっていることがあります。問い合わせの際は、まず希望時間帯の空き状況を確認してください。

2. 緊急時・土日祝の対応を確認する

24時間対応か、土日祝も訪問できるか、急な追加依頼にどこまで応じてもらえるか。上の一覧には各事業所の「電話受付時間」と「受付休業日」を載せています。ここが自分の生活時間と合うかを先に見ておくと、問い合わせの空振りが減ります。

3. 自費サービスの有無と料金を先に聞く

介護保険では頼めない作業が必ず出てきます。同じ事業所が自費プランを持っていれば、別業者を探す手間が省けます。1時間あたりの料金と最低利用時間を確認しておきましょう。

4. 担当ヘルパーの交代ルールを聞く

「毎回同じ人が来るのか」「体調不良時の代替は用意されるのか」は満足度に直結します。認知症のある方の場合は、担当固定を明確に希望として伝えてください。

よくある質問

練馬区で訪問介護を使うには、まず何をすればいいですか？

お住まいの地区を担当する「地域包括支援センター（地域包括支援センター）」に相談するのが最初の一歩です。要介護認定の申請方法から、ケアマネジャー（居宅介護支援事業所）の紹介まで無料で案内してもらえます。

練馬区には訪問介護事業所が何件ありますか？

2026年9月時点で、介護情報サイトの掲載ベースで約180件の訪問介護事業所が練馬区内にあります。本ページではそのうち20件を連絡先つきで掲載しています。全件は厚生労働省「介護サービス情報公表システム」で確認できます。

訪問介護の自己負担はいくらくらいですか？

練馬区は介護報酬の地域区分で1級地（1単位＝11.40円）にあたります。自己負担1割の場合、身体介護20分以上30分未満で約278円、生活援助20分以上45分未満で約204円が目安です（各種加算は別途）。

ヘルパーに家族の分の食事や庭の草むしりも頼めますか？

介護保険の訪問介護では頼めません。訪問介護は利用者本人の生活に必要な支援に限られ、家族分の家事、来客対応、庭の手入れ、大掃除などは対象外です。保険外の自費サービスや家事代行を併用する方法があります。

事業所は途中で変更できますか？

変更できます。担当のケアマネジャーに相談すれば、ケアプランを見直したうえで別の訪問介護事業所に切り替えられます。相性やシフトの都合で変更する方は珍しくありません。

要介護認定の結果が出る前でもサービスを使えますか？

申請日にさかのぼってサービスを利用できる「暫定ケアプラン」という仕組みがあります。ただし想定より低い介護度で認定された場合、超過分が全額自己負担になるリスクがあります。利用を急ぐ場合は、必ずケアマネジャーとリスクを確認したうえで進めてください。
